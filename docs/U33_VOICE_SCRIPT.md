Numbered lines for voice generation. Name each audio file with its number (`001.mp3`, `102.mp3`). Paste only the text after the number into the voice tool. One block per speaker, so each block uses one voice.

- **Part 1, cutscene lines (001 to 020):** 1007 characters. Do these first.
- **Part 2, existing story lines (100 to 254):** 9857 characters. Spoken in missions, act transitions and the Tower. Do these as your plan allows.
- Subtitles still show for any line without a file, so you can add files gradually.
- Typos in the old dialogue file were fixed here (stray quote, "signature", "its end", "Devils'", "Io"). Rasputin lines are Russian. Use a voice that supports Russian, or skip them (they stay subtitled).
- Riven's line had a stage direction "(in Ikora's voice)". It is removed from the text. Ask for Ikora's voice on that one if you like.
- **Ghost's voice is decided:** ElevenLabs "Phil - Robotic and Synthetic". All 82 Ghost lines are generated and split (files `assets/voice/001.mp3` and so on, named by line number). Any extra in-game robot effect on top of Phil is optional and light. Crota deep and hollow. Calus calm and regal. Mara Sov calm, cool and measured.

- Lines 009, 012, 013 and 014 are the Glimmer scene (Ghost shows the Vanguard the Cabal-signature Glimmer from the Devils' Lair). It leads into the existing Ikora lines about who is paying the Fallen.
